# P12g — 逆転は「積み上がった KV」由来。決め手は層14-20 の KV

2026-09-15 / Qwen3-0.6B 28層 KV256 / Host CPU / P12f の点B（「音楽をかけて」直後・prefix 80）

## 結論

1. **逆転の主因は focused が積み上げた KV。** 最終ステップを FP32 にしても、focused の KV だけで
   「音」−「エ」の差が **+5.07 → +1.64（−3.43）** に削られる。最終ステップの影響は約 −1。
2. **効いている KV は層14-20。** focused の KV のうち層14-20 だけを FP32 に戻すと **+1.64 → +3.63**。
   層0-6 は +0.09、層7-13 は +0.25、層21-27 は +1.01。4群の回復量の合計 3.34 は全体の 3.43 とほぼ一致（ほぼ加法的）。
3. **focused の KV は、全層で baseline より FP32 に「近い」のに、答えを壊す。**
   例: 層14 の V は baseline 68.6% → focused 54.6%。**誤差の大きさではなく向き**が効いているという
   P12f の読みを、KV の側でも確認した。
4. Host QDQ の V キャッシュは baseline でも FP32 から **31〜69%** ずれている（層0 から既に 31%）。

## 1. KV × 最終ステップの 3×3

prefix の最後の1トークン手前（79）まで各モデルで KV を積み、最後の1ステップだけ別モデルで計算。
値は「音」−「エ」の logit 差（FP32 は +5.07、負で逆転）。

| KV ＼ 最終ステップ | FP32 | baseline | focused |
|---|---:|---:|---:|
| FP32 | **+5.07** | +4.23 | +4.00 |
| baseline | +3.61 | +3.35 | +2.48 |
| focused | **+1.64** | +0.70 | **−0.38（エ）** |

自前同士の値は P12f と一致（fp32 18.76/13.68、baseline 18.23/14.88、focused 16.11/15.73）。

### 加法性

| 効果（FP32/FP32 からの差） | 値 |
|---|---:|
| baseline の KV だけ | −1.46 |
| focused の KV だけ | **−3.43** |
| baseline の最終ステップだけ | −0.84 |
| focused の最終ステップだけ | −1.07 |

| 組み合わせ | 足し算の予測 | 実測 | 相互作用 |
|---|---:|---:|---:|
| focused KV × baseline step | +0.80 | +0.70 | −0.10 |
| baseline KV × focused step | +2.54 | +2.48 | −0.06 |
| baseline KV × baseline step | +2.77 | +3.35 | +0.58 |
| **focused KV × focused step** | **+0.57** | **−0.38** | **−0.95** |

大半は足し算で説明でき、focused 同士だけ約 −0.95 の上乗せがあり、それが境界を越える最後の一押しになっている。

## 2. どの層の KV か

focused の KV のうち一部の層だけを差し替えて、最後の1ステップを計算。

| 差し替えた層 | FP32 の KV に / 最終 FP32 | FP32 の KV に / 最終 focused | baseline の KV に / 最終 focused |
|---|---:|---:|---:|
| なし | +1.64 | −0.38 エ | −0.38 エ |
| 層0-6 | +1.73 | +0.55 | −0.82 エ |
| 層7-13 | +1.89 | −0.22 エ | −0.11 エ |
| **層14-20** | **+3.63** | **+2.22** | **+1.68** |
| 層21-27 | +2.65 | +0.85 | −0.11 エ |
| 最後4層(24-27) | +2.47 | +0.85 | −0.46 エ |
| 最後8層(20-27) | +2.71 | +0.84 | +0.02 |
| 最後12層(16-27) | +4.33 | +2.79 | +1.70 |
| 最初14層(0-13) | +2.17 | +0.30 | −0.42 エ |
| 全層 | +5.07 | +4.00 | +2.48 |

- 3列とも**層14-20 の差し替えだけで「音」に戻る**（baseline の KV でも +1.68）
- 「最後の4層だけ戻す」は効かない（baseline の KV では −0.46 のまま）。**最終層付近ではなく中深層**

## 4. 読み方の注意

- KV 差し替えは「**どの層の状態**が効くか」を示す。層14 の KV は、層0-13 の残差を通って作られるので、
  **その誤差を作った範囲変更が層14-20 にあるとは限らない**。範囲をどこで戻せば直るかは別の実験が要る
- 1つの対話・1つの分岐点での結果。一般化はまだしない

## 5. 次の候補

1. **誤差の「向き」を測る**: 層14-20 の KV 誤差が、79スロットにわたって**そろった偏り**（系統誤差）か、
   ばらばらな雑音かを比べる。baseline は L2 が大きくても雑音で、attention の平均で打ち消し合い、
   focused は小さくても偏りで、打ち消し合わない、という仮説を検証する（再ビルド不要）
2. **範囲の戻し方の実験（Host のみ・initializer の書き換えだけ）**: focused の範囲変更を
   「層14-20 だけ baseline に戻す」「層0-13 だけ戻す」で作り、点B の差と自由生成を見る
