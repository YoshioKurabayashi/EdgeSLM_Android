# P12h — KV 誤差の「向き」：判定に効く成分はごく小さく、focused はそこを悪くした

2026-09-15 / Qwen3-0.6B 28層 KV256 / Host CPU / P12f の点B（「音楽をかけて」直後・prefix 80）

## 結論

1. **層ごとの「向きのそろい方」と「attention への効き方」では、focused の悪化は見えない。**
   bias ratio・スロット間 cosine・PC1 は focused がわずかに高いだけで、baseline も独立雑音の目安（0.113）より
   ずっと高い。attention の Δscore・重みの KL・重み付き V 誤差・attention 出力誤差は、**ほぼ全層で focused の方が良い**。
2. **判定（「音」−「エ」）への一次近似の寄与で見ると、はっきり分かれる。**
   FP32 の勾配 g_L を各層の attention 出力に取り、KV 誤差が作るずれ Δy_L に射影すると、
   全層の合計は **baseline −2.23 / focused −3.71**（P12g の差し替え実測 −1.46 / −3.43 とおおむね一致）。
   差の大半は **層15-21**。
3. **focused は、どの層でも誤差の大きさ |Δy| は小さいのに、判定を悪くする向きの成分が増えた。**
   例: 層20 |Δy| 13.33→12.33 だが cos(Δy, g) +0.001→−0.035、層21 10.48→7.52 だが +0.060→−0.064。
   baseline の大きな誤差は判定方向とほぼ直交しており無害だった。
4. **判定に効く成分は誤差全体のごく一部**（|cos| はすべて 0.14 未満）。L2 や層ごとの attention 指標が
   この変化を捉えられないのは当然で、それらは判定と直交する 99% 側に支配されている。

## 2. 判定への一次近似の寄与

g_L = ∂(logit音 − logitエ)/∂(層L の self_attn 出力・最終位置)（FP32 公式モデルで逆伝播）。
Δy_L = 量子化 KV（最新スロットと q は FP32）での attention 出力 − FP32 の attention 出力。
寄与 = g_L · Δy_L（他の層の KV は正しいとした一次近似。負 = 「エ」寄りに押す）。

## 3. 読み方

- **勾配 |g| は深いほど小さい**（層0 2.86 → 層27 0.24）。**|Δy| は深いほど大きい**（層24-26 で 14〜20）。
  両者がそろって大きいのが**層16-18**で、ここが判定への寄与の中心になる
- 層24-26 は |Δy| が最大級でも |g| が小さく cos もほぼ 0 なので、判定への影響は小さい
- 層16-17 は V 由来、層18・21 は K 由来の寄与が大きい
- この値は**この1つの判定**（点B の「音」対「エ」）に対するもの。別の判定では g の向きが変わるので、
  「層16-21 の誤差は常に有害」とは言えない。言えるのは「層16-21 は attention 出力の誤差が大きく、
  かつ判定への感度も残っている層なので、ここの KV を作る範囲変更は向きしだいで答えを変えやすい」まで

## 4. 次の候補

1. **範囲の戻し方の実験（Host のみ・initializer の書き換えだけ）**。
   評価は L2 ではなく「音−エ」などの**判定マージン**で行い、**1つの判定に合わせ込まない**よう
   判定点を複数用意する（点B、3ターン目の「22度」、英語対話の参照、P12f 点A）
2. 変更の単位は「層ブロック（0-13 / 14-20 / 21-27）× テンソル種別（残差 add / RMSNorm 補助 / その他）」
